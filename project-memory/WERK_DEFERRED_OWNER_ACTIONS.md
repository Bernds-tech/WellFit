# WERK Deferred Owner Actions

Aktuell keine ausdrücklich vom Owner auf später verschobene WERK-Aktion.

Regel:
- Eine Aktion kommt hier nur hinein, wenn Bernd sie ausdrücklich verschiebt.
- Deferred bedeutet offen, aber nicht erneut nachfragen.
- Der Builder darf parallel-sichere Arbeit weiterführen.
- Bei expliziter Wiederaufnahme wird der Eintrag aktualisiert und die ursprüngliche Finishline-Priorität wiederhergestellt.
