# Project Memory V4 — Execution Continuity

V4 adds persistent execution continuity across chats/sessions.

Required artifacts:
- `STARTED_WORK.md`
- `WORK_LOCKS.md`
- `EXECUTION_RECEIPTS.md`
- `RECONCILIATION.md`

Rules:
- substantive work must be recorded before implementation continues;
- unfinished work must stay visible across sessions;
- a stale lock is not automatically free;
- completion requires reconciliation against current GitHub evidence;
- do not silently restart, duplicate or erase prior work.
