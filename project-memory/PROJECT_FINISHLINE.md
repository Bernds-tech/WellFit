# WellFit Finishline

Human-readable finishline for the visual/landing/UI repository.

## Gates
- Visual system
- Landing/UI
- Technical capability alignment with WellFit-now and WellFit-Buddy
- Cross-repository handoff/convergence readiness

Machine state lives in `FINISHLINE_STATE.json`.

## Rules
- Implementation is not visual acceptance.
- Do not claim a feature visually supported when the owning technical repository does not support it.
- External/owner visual acceptance cannot be inferred from repository code alone.
- Convergence of the three WellFit repositories is planned but not scheduled; no target repository or date is assumed.
